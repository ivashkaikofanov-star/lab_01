# lab_01

Программа с двумя утилитами: калькулятором и конвертером единиц.

## Что умеет

**Калькулятор:**
- операции `+`, `-`, `*`, `/`
- целые и вещественные числа
- унарный плюс и минус (`-5`, `2 * -3`, `1 + -2`)
- пробелы игнорируются
- приоритет операций соблюдается (`2 + 3 * 4` = 14)
- ведущие нули работают (`007` = 7)

**Конвертер:**
- длина: `mm`, `cm`, `m`, `km`
- масса: `g`, `kg`
- температура: `c`, `f`, `k`
- регистр единиц не важен (`MM` = `mm`)
- конвертация между разными группами запрещена
- температура ниже абсолютного нуля запрещена

## Установка

    pip install -e .

Если нужны тесты и линтер:

    pip install -e ".[test,lint]"

## Как пользоваться

Калькулятор:

    python -m toolkit calc "4 + 9 * 4"

Выведет `40`.

Конвертер:

    python -m toolkit convert 10000 --from mm --to m

Выведет `10`.

Справка:

    python -m toolkit --help

## Ошибки

Если что-то не так, программа выводит сообщение в поток ошибок и завершается с кодом 2. Например:

    python -m toolkit calc "1 / 0"

Выведет `Ошибка: Деление на ноль`.

## Структура

    src/toolkit/
      __init__.py
      __main__.py       — точка входа CLI
      calculator.py     — ядро калькулятора
      converter.py      — ядро конвертера

    units.json          — таблица единиц для конвертера
